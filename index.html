Données

Vos données restent dans ce navigateur, sur cet appareil : rien n'est envoyé en ligne et rien n'est écrit dans le code de la page. Pour les retrouver ailleurs, copiez l'export JSON. La version Raspberry Pi remplacera cette couche par PocketBase.
CSV avec une ligne d'en-tête, séparateur « ; » ou « , ». Colonnes reconnues (ordre libre) : sku, nom, categorie, prix, rop, stock, poids, lien, type (type = composant ou fini). Les SKU déjà existants sont mis à jour, les autres créés. Depuis Excel : Fichier → Enregistrer sous → CSV UTF-8.
